------------------------------------------------------------
STEP 1 — Purani folder ka backup (1 minute)
------------------------------------------------------------
1. GitHub Desktop kholein
2. Repository ▸ Show in Explorer
   (aap ki folder: D:\ZNZ\New folder\ZNZ)
3. Us folder ko copy kar ke ek jagah rakh dein (backup ke liye)

------------------------------------------------------------
STEP 2 — Sirf .git chhorein, baqi sab delete karein
------------------------------------------------------------
1. Usi folder (D:\ZNZ\New folder\ZNZ) me jayein
2. View menu ▸ Hidden items par tick lagayein (taake .git nazar aaye)
3. Ctrl + A se sab select karein
4. Ctrl + dabaye rakhte hue **.git** par click karein (uska selection hat jayega)
5. Delete dabayein — baqi sab chala jayega, .git mehfooz rahega
   (Ye zaroori hai: purani settings/data naye code se mix na hon)

------------------------------------------------------------
STEP 3 — Naye ZIP ka material paste karein
------------------------------------------------------------
1. Naya ZIP extract karein → andar ek folder hoga: ZNZ-WEBSITE-FINAL-8.3.0
2. Us folder ko kholein, Ctrl + A, Ctrl + C
3. Wapas D:\ZNZ\New folder\ZNZ me aayein, Ctrl + V
   (ab .git ke saath naya code, public, lib, data, package.json sab aa jayega)

------------------------------------------------------------
STEP 4 — GitHub Desktop se push
------------------------------------------------------------

2. Changes me bohat si files dikhengi — yeh normal hai (naya version)

5. Upar "Push origin" dabayein
6. Agar "Pull origin" kahe to pehle Pull, phir Push
